# LeanCart Bulk Price Changer

[![License: GPL v2](https://img.shields.io/badge/License-GPLv2-blue.svg)](LICENSE.txt)
[![WordPress](https://img.shields.io/badge/WordPress-6.2%2B-21759b.svg)](https://wordpress.org/)
[![WooCommerce](https://img.shields.io/badge/WooCommerce-8%2B-7f54b3.svg)](https://woocommerce.com/)

Updates the prices of hundreds of products by percentage or fixed amount in seconds.

**Example site:** https://findsleepdoctors.com
**Category:** Pricing & Profit · **License price:** $29 (Business Bundle: $149)

## Features
* Percentage or fixed amount
* Category filter
* Preview (how many products will be affected)
* Sale price and variation support
* Reversible backup (button to restore old prices)

## Installation
1. Download the ZIP from `build/zips/` or download this repository as a ZIP.
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin.
3. Activate the plugin and configure it at **Settings → LeanCart Bulk Price Changer**.

## Requirements
- WordPress 6.2+, PHP 8.0+
- WooCommerce 8+ (HPOS compatible)
